## ✨ Features & Architecture

### 1. Animated Luxury Hero Experience
- **Desktop Hero:** High-impact animated background using direct reference photography (`hero-desktop.png`), subtle Ken Burns zoom, warm lighting shimmer bloom, and architectural calligraphy badge *"Your Dream Our Design"*.
- **Mobile Hero:** Responsive animated portrait hero (`hero-mobile.png`) with clean typography, quick actions, and touch optimization.
- **Floating Luxury Badges:** Modern Designs, Premium Materials, and Expert Execution with gold iconography.

### 2. Multi-Page Architecture & Dynamic Routes
Every link opens its own dedicated, rich, grand page:
- `/` — Homepage (Hero, Trust Strip, Services Preview, Interactive Transformations, Why Choose Us, Client Testimonials)
- `/about` — About Us (Company philosophy, values, standards, in-house modular workshop)
- `/services` — All 14 specialized design & manufacturing services with category filters
- `/services/:id` — Dedicated full detail page for each service with features, materials, scope, timeline, and prefilled inquiry form
- `/projects` — Filterable architectural project portfolio with image lightbox
- `/projects/:id` — Dedicated project showcase with high-res gallery and specifications
- `/before-after` — Interactive Before & After comparison suite with draggable slider
- `/process` — Our 5-Stage Journey (Consultation, Planning, Design Development, Execution Coordination, Final Review)
- `/contact` — Comprehensive Consultation Booking with phone validation, WhatsApp integration, and Google Maps directions

### 3. Interactive Before & After Transformation Slider
- Draggable gold vertical divider handle `< >`
- Responsive touch-friendly dragging without blocking vertical page scrolling
- Keyboard navigation with `←` and `→` arrow keys
- High-resolution aligned room comparisons

### 4. Direct WhatsApp & Dual Call Integrations
- Floating WhatsApp button with pulsing beacon on desktop
- Mobile bottom sticky quick-action bar with direct WhatsApp and Call buttons matching reference
- Pre-filled URL-encoded enquiry messages containing user's project type, budget, and service requirements

## 🛠️ Tech Stack

- **Framework:** React 19 + TypeScript
- **Bundler:** Vite 6
- **Styling:** Tailwind CSS with custom editorial tokens (Ivory, Champagne Gold, Espresso, Charcoal)
- **Icons:** Lucide React + custom vector marks
- **Routing:** React Router 7
- **Animations:** CSS keyframes + Canvas Confetti on booking

---

## 🚀 Running Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
